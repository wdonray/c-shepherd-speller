# Teacher feedback log

Every piece of feedback from a real teacher using PatternSpell, anonymized, with what we did about it. This is how we learn from our mistakes.

## Privacy rule

This repository is public. Never put a teacher's email address, full name, school, or anything that identifies a student in this log. First name and grade only (for example, "Maya, grade 2"). Contact details live privately at `~/workspace/patternspell-teacher-outreach/contacts.md`.

## How to log feedback

When a feedback email lands (or a teacher replies to an outreach email):

1. Add a row to the table below.
2. File the substance as an issue: `bug` for something broken, `idea` for something missing. Link it in the Action column.
3. Reply to the teacher personally. Say what changed, or what will not change and why. Note the reply date.
